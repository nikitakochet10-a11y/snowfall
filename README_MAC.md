# Snowfall для macOS

## Запуск из исходников (для проверки на арендованном Mac)
```
# (из папки с этими файлами)
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements-mac.txt
python3 Snowfall.py
```
Значок появится в строке меню (справа вверху), панель откроется сама.

## Сборка .app
`bash build_mac.sh` → `dist/Snowfall.app` и `dist/Snowfall-mac.zip`.
Или через GitHub: загрузи содержимое папки (вместе со скрытой .github) в корень репозитория, Actions → «Build macOS app» → Run workflow → скачай артефакт
(arm64 — для M1/M2/M3, intel — для старых Mac).

## Первый запуск скачанной сборки
Приложение не подписано сертификатом Apple, поэтому: правый клик → «Открыть» → «Открыть».
Если пишет «повреждено»: `xattr -cr Snowfall.app`.

## Что отличается от Windows
- Разрешения не нужны: границы окон и названия программ macOS отдаёт без них.
  (Заголовки окон видны только после «Запись экрана»; без неё правила называются по программе.)
- Dock: снег лежит на нём, если Dock снизу и не прячется.
- Варежка: системный курсор на Mac заменить нельзя — варежка видна над окнами Snowfall (в режимах лепки/размещения).
- Esc, как и в Windows, освобождает мышь.
- Повторный запуск не создаёт копию, а открывает панель.

## Что проверить в первую очередь
1. Снег ложится на верхние края окон и едет за ними при перетаскивании.
2. Нет ли снега на меню-баре/Dock там, где его быть не должно; сам Dock как поверхность.
3. Клики проходят сквозь оверлей (можно работать в других программах).
4. Кот, снеговик, ёлка кликаются; режимы лепки/размещения/наряжания ловят мышь.
5. Полноэкранное приложение (Safari/видео) ставит снег на паузу.
6. Несколько рабочих столов (Spaces): оверлей виден на каждом.
7. Внешний монитор: оверлей покрывает только основной экран.

## Бесплатная проверка через GitHub Actions
Workflow собирает приложение, запускает его на Mac-сервере GitHub, делает скриншоты экрана и сохраняет лог.
В артефакте `Snowfall-mac-*` лежат: `report/platform_check.txt` (проверка слоя macOS), `report/run.log`
(вывод и ошибки приложения), `report/screen1.png`, `report/screen2.png` и `Snowfall-mac.zip`.
